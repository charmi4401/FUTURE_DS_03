# Bank Campaign Performance Analysis

**Future Interns – Data Science & Analytics, Task 3**

## 1. Project Description

This project analyzes bank telemarketing campaign data to understand term-deposit subscription outcomes and compare conversion rates across customer and campaign groups.

## 2. Tools Used

- Python
- Pandas
- Power BI Desktop
- CSV files

## 3. Main Files

### Script and Data

- `bank_additional_full.py`: Python script for data preparation and analysis.
- `bank_additional_full.csv`: Original dataset.
- `bank_fixed.csv`: Corrected CSV file created by the script.
- `bank_marketing_cleaned.csv`: Cleaned dataset after duplicate removal.

### Analysis Outputs

- `campaign_summary.csv`: Overall campaign summary.
- `conversion_by_job.csv`: Conversion results by job category.
- `conversion_by_contact.csv`: Conversion results by contact method.
- `conversion_by_marital_status.csv`: Conversion results by marital status.
- `conversion_by_education.csv`: Conversion results by education.
- `conversion_by_month.csv`: Conversion results by month.
- `conversion_by_day.csv`: Conversion results by day of the week.
- `conversion_by_age_group.csv`: Conversion results by age group.
- `conversion_by_campaign_contacts.csv`: Conversion results by current campaign contact group, if generated by the script.
- `conversion_by_housing_loan.csv`: Conversion results by housing-loan status.
- `conversion_by_personal_loan.csv`: Conversion results by personal-loan status.
- `conversion_by_previous_contacts.csv`: Conversion results by previous-contact group.

### Dashboard and Report

- `Bank_Campaign_Performance_Dashboard.pbix`: Power BI dashboard file (the exact saved filename may differ).
- `Insights_and_Recommendations.txt`: Key findings and recommended next steps.

## 4. How to Run the Python Script

1. Install Python if it is not already installed.
2. Open a terminal in the project folder.
3. Install Pandas by running `python -m pip install pandas`.
4. Make sure `bank_additional_full.csv` is in the same folder as the Python script.
5. Run `python bank_additional_full.py`.

If the `python` command is not recognized, use the Python executable configured on your computer. The script creates the corrected and cleaned CSV files and the analysis output files defined in the code.

## 5. How to Open the Power BI Dashboard

1. Open Power BI Desktop.
2. Open the saved `.pbix` dashboard file.
3. Use the slicers to filter the results by job, month, previous campaign outcome, or contact method.
4. Clear the slicer selections to return to the overall view.

## 6. Main Results

- **Total records analyzed:** 41,176
- **Subscribed:** 4,639
- **Not subscribed:** 36,537
- **Overall conversion rate:** 11.27%

## 7. Notes

- `y = yes` means the customer subscribed to a term deposit; `y = no` means they did not.
- The dataset's `unknown` category values are retained as categories and are not automatically treated as missing values.
- The analysis describes observed associations; it does not prove cause and effect.
